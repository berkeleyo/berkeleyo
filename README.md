I work on the infrastructure and automation behind complex production systems. Much of that work sits where networking, cloud infrastructure, security and software meet — across distributed, multi-vendor environments where changes need to be controlled, observable and repeatable.

I'm interested in building practical tooling that makes these environments easier to operate: infrastructure validation, deployment pipelines, API integrations and increasingly AI-assisted workflows.

This GitHub is where I develop and document independent implementations of those ideas.

## Selected work

A few projects that reflect the problems I like working on. These are public reference implementations, not copies of employer or customer infrastructure.

| Project | What it explores |
| --- | --- |
| [Production Cloud Network Platform](https://github.com/berkeleyo/production-cloud-network-platform) | Azure hub-and-spoke networking, segmented workloads, WAF ingress and offline Terraform validation. |
| [AKS GitOps](https://github.com/berkeleyo/azure-aks-gitops) | Kubernetes infrastructure, GitOps-driven configuration, environment promotion and operational runbooks. |
| [Access Governance Request Platform](https://github.com/berkeleyo/access-governance-request-platform) | Request and approval workflows, time-bound access and auditable identity operations. |
| [Azure Governance Baseline](https://github.com/berkeleyo/azure-governance-baseline-framework) | Policy-as-code, naming and tagging standards, drift reporting and controlled remediation patterns. |

These are the current selections; I'll revisit them as I improve and expand the underlying projects.

## Engineering interests

**Infrastructure & architecture** — Multi-region cloud and hybrid environments, network design, secure connectivity, edge services and resilient systems.

**Automation & delivery** — Infrastructure as code, CI/CD, reusable tooling, API integrations, validation and change management.

**Security & operations** — Identity and privileged access, policy enforcement, observability, incident investigation and operational reliability.

**What I'm exploring** — AI-assisted infrastructure operations, developer tooling and ways to make complex systems easier to understand and maintain.
